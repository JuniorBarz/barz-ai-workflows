# Exemplos sintéticos

Substitua este arquivo por uma explicação dos exemplos do workflow.

Inclua:

- uma entrada pequena criada do zero;
- casos normais, ausentes, inválidos e conflitantes;
- uma saída esperada com contagens verificáveis;
- parâmetros marcados como demonstração;
- uma declaração explícita de que todos os dados são sintéticos.

Não use nomes, códigos, preços, datas, descrições ou estruturas copiadas de arquivos privados. Não apresente dados reais parcialmente mascarados como exemplo sintético.
